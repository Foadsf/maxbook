Keyboard shortcuts

On a Mac, use Cmd where this page says Ctrl. F1 in Maxbook shows the most important ones:

Writing

$

Formula in the text (inline)

$ in an empty inline formula

Make it a display formula on its own line

Ctrl+M / Ctrl+Shift+M

Inline formula / display formula

>> and space, ``` and space, Ctrl+Alt+M

Maxima block

#, ##, ###, #### and space

Heading 1 to 4

-, * or + and space

Bulleted list

1. and space

Numbered list

> and space

Quote

---

Horizontal line

**text**

Bold

`text`

Code

Ctrl+B, Ctrl+I, Ctrl+`

Bold, italic, code

Ctrl+Alt+1 … Ctrl+Alt+4, Ctrl+Alt+0

Heading 1–4, plain text

Ctrl+[ / Ctrl+]

Outdent / indent a list item

Shift+Enter in text

Line break

Ctrl+Z, Ctrl+Y or Ctrl+Shift+Z

Undo, redo

In a formula

/

Fraction

^, _

Exponent, subscript

→

Leave a fraction, exponent or subscript; at the end, leave the formula

a word (int, frac, sum, prod, lim, sqrt, matrix, det, …​)

Search templates; Enter or Tab inserts, ↑ ↓ choose, Space keeps the letters

Tab with empty boxes

Next box

= then Tab

Compute in place

:= then Tab

Define in Maxima

Tab otherwise

Leave the formula

Esc

Leave the formula

Enter

Leave an inline formula

Shift+Enter in a display formula

Evaluate it like a Maxima block, then move on

Maxima blocks

Shift+Enter

Run, then move on

Ctrl+Enter

Run and stay

Alt+Enter

Run and insert a new block below

Tab / Shift+Tab

Indent / outdent

Esc

Select the block (Enter goes back in, Delete removes it)

↑ on the first line, ↓ on the last

Move into the text

Backspace in an empty block

Remove it

Notebook

Ctrl+Shift+Enter

Ctrl+S, Ctrl+Shift+S

Save, save as

Ctrl+O

Ctrl+Alt+N
