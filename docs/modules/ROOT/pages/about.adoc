== Built on

* https://maxima.sourceforge.io/[Maxima] does all the mathematics.
Maxbook talks to it as a separate program over a pipe and does not include it.
* https://cortexjs.io/mathlive/[MathLive] (MIT) is the formula editor and renders the mathematics, with the KaTeX fonts (MIT).
* https://prosemirror.net/[ProseMirror] (MIT) is the document editor, and https://github.com/markdown-it/markdown-it[markdown-it] (MIT) reads Markdown.
* http://www.gnuplot.info/[gnuplot] draws the plots, through Maxima.
* The optional AI helper uses Anthropic's Claude through the official `anthropic` Python package (MIT).
* The single-file programs are built with https://pyinstaller.org/[PyInstaller].
* This site is built with https://antora.org/[Antora], its default UI (MPL-2.0) and Asciidoctor Tabs (MIT).

The full list, with versions and licence files, is in {repo-url}/blob/main/THIRD_PARTY_NOTICES.md[THIRD_PARTY_NOTICES.md].
