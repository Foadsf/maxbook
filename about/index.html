Built on

  • Maxima does all the mathematics. Maxbook talks to it as a separate program over a pipe and does not include it.

  • MathLive (MIT) is the formula editor and renders the mathematics, with the KaTeX fonts (MIT).

  • ProseMirror (MIT) is the document editor, and markdown-it (MIT) reads Markdown.

  • gnuplot draws the plots, through Maxima.

  • The optional AI helper uses Anthropic’s Claude through the official anthropic Python package (MIT).

  • The single-file programs are built with PyInstaller.

  • This site is built with Antora, its default UI (MPL-2.0) and Asciidoctor Tabs (MIT).

The full list, with versions and licence files, is in THIRD_PARTY_NOTICES.md.
